# x86 Assembly Language: Systems Programming Lab Suite
A comprehensive collection of low-level programs and laboratory exercises focusing on 8086 microprocessor architecture and register-level logic.

## 📊 Overview
This repository contains a structured series of programs developed during my 2nd-year Computer Architecture coursework at Arellano University. The suite progresses from basic data movement to complex algorithmic logic, providing deep insight into how software interacts directly with CPU hardware.

## 🚀 Key Learning Milestones
- **Register Manipulation:** Mastery of general-purpose (AX, BX, CX, DX) and segment registers.
- **Arithmetic & Logic Operations:** Implementation of math and boolean logic at the bit level.
- **Interrupt Handling:** Utilizing DOS interrupts (e.g., `INT 21h`) for screen output and keyboard input.
- **Flow Control:** Constructing loops, conditional jumps, and subroutines without high-level abstractions.
- **Low-Level Debugging:** Understanding memory maps, object code generation, and segment addressing.

## 🛠 Tech Stack & Environment
- **Architecture:** x86 (8086 Instruction Set)
- **Assembler:** Turbo Assembler (TASM)
- **Linker:** Turbo Linker (TLINK)
- **Emulator:** DOSBox (16-bit DOS environment)

## 📂 Project Structure
- **Lab Modules (`labA1-1.asm` to `labA1-4.asm`):** Introductory modules focusing on environment setup and basic syntax.
- **Exercise Suite (`labExA.asm` to `labExF.asm`):** Applied logic exercises for string handling and arithmetic.
- **Program Sequence (`pr1.asm` to `pr25.asm`):** A comprehensive 25-program series covering advanced topics like array processing, stack operations, and complex branching.
- **Build Tools:** Includes `TASM.EXE` and `TLINK.EXE` for local assembly and linking within the DOSBox environment.
